## #

- **429** — HTTP "Too Many Requests"; rate limit or quota exceeded. [→](./02-calling-models/06-errors-retries-rate-limits.md)
- **`*args` / `**kwargs`** — collect extra positional / keyword arguments. [→](./00-python-for-ai/05-functions-arguments.md)
- **`.env` file** — local file of `KEY=value` lines loaded into the environment during development. [→](./00-python-for-ai/10-api-keys-env.md)
- **`.gitignore`** — file listing paths Git should not track. [→](./00-python-for-ai/13-git-github.md)
- **`@tool`** — decorator that turns a Python function into a tool, using its docstring and type hints. [→](./07-agentic-ai/00-course/d-langchain-agents/01-single-agent-with-langchain.md)
- **`@traceable`** — decorator that traces any Python function. [→](./07-agentic-ai/00-course/f-build-an-agentic-chatbot/04-tracing-the-chatbot-with-langsmith.md)
- **`add_messages`** — reducer that appends chat messages and replaces ones with matching ids. [→](./07-agentic-ai/00-course/e-langgraph-core/02-langgraph-core-components.md)
- **`asyncio.gather`** — run several awaitables concurrently and collect results in order. [→](./00-python-for-ai/12-async-basics-youll-see-in-agents.md)
- **`await`** — suspend until an awaitable finishes, letting other tasks run. [→](./00-python-for-ai/12-async-basics-youll-see-in-agents.md)
- **`BaseModel`** — the base class for Pydantic models. [→](./00-python-for-ai/08-pydantic.md)
- **`bind_tools`** — attaches tool schemas to a chat model so it can request calls. [→](./03-prompting-llm-apps/07-building-llm-apps-with-langchain.md)
- **`Command(resume=...)`** — input that resumes a paused thread; the value becomes `interrupt()`'s return. [→](./07-agentic-ai/00-course/f-build-an-agentic-chatbot/06-human-in-the-loop-with-interrupt.md)
- **`Command.PARENT`** — target that lets a subgraph node route to a node in its parent. [→](./07-agentic-ai/00-course/g-mcp-and-subgraphs/02-langgraph-subgraphs.md)
- **`create_agent`** — v1 function that builds a tool-calling agent loop on LangGraph. [→](./04-rag/13-updated-langchain.md)
- **`enumerate` / `zip`** — loop helpers for index+item and parallel iteration. [→](./00-python-for-ai/04-control-flow-comprehensions.md)
- **`Field`** — adds defaults, constraints and descriptions to a field. [→](./00-python-for-ai/08-pydantic.md)
- **`generate()`** — the method that runs autoregressive decoding. [→](./06-fine-tuning/05-hugging-face-transformers.md)
- **`init_chat_model`** — loads a chat model from any supported provider by a string ID. [→](./04-rag/13-updated-langchain.md)
- **`interrupt(value)`** — pauses the graph inside a node and surfaces `value` to the caller. [→](./07-agentic-ai/00-course/f-build-an-agentic-chatbot/06-human-in-the-loop-with-interrupt.md)
- **`pathlib.Path`** — object-oriented file paths; `/` joins parts. [→](./00-python-for-ai/07-error-handling-files.md)
- **`pipeline`** — high-level helper that bundles tokenizer, model and post-processing. [→](./06-fine-tuning/05-hugging-face-transformers.md)
- **`python-dotenv`** — library that loads `.env` files. [→](./00-python-for-ai/10-api-keys-env.md)
- **`recursion_limit`** — maximum number of graph steps before the run is stopped. [→](./07-agentic-ai/00-course/d-langchain-agents/01-single-agent-with-langchain.md)
- **`response_format`** — schema for a structured final answer from the agent. [→](./07-agentic-ai/00-course/d-langchain-agents/01-single-agent-with-langchain.md)
- **`st.cache_resource`** — caches expensive objects (clients, models) across reruns. [→](./00-python-for-ai/14-build-a-ui-fast.md)
- **`st.session_state`** — per-user dict that persists across Streamlit reruns. [→](./00-python-for-ai/14-build-a-ui-fast.md)
- **`st.write_stream`** — Streamlit helper that renders a generator of strings live. [→](./07-agentic-ai/00-course/f-build-an-agentic-chatbot/03-streaming-chat-threading.md)
- **`stream_mode="messages"`** — LangGraph mode that yields LLM message chunks with node metadata. [→](./07-agentic-ai/00-course/f-build-an-agentic-chatbot/03-streaming-chat-threading.md)
- **`tools_condition`** — prebuilt router: to `"tools"` if there are tool calls, otherwise END. [→](./07-agentic-ai/00-course/f-build-an-agentic-chatbot/05-tools-in-the-agentic-chatbot.md)
- **`try/except/else/finally`** — catch errors, run code on success, always clean up. [→](./00-python-for-ai/07-error-handling-files.md)
- **`with_structured_output`** — LangChain method that makes a chat model return instances of a schema. [→](./07-agentic-ai/00-course/c-python-for-agents/02-pydantic-for-agents.md)

## A

- **Adaptive RAG** — choosing a retrieval strategy per query based on predicted complexity. [→](./04-rag/21-adaptive-rag-self-rag.md)
- **Agent** — an LLM in a loop that chooses actions (tool calls) and observes their results. [→](./04-rag/12-ai-agents-agentic-ai.md)

- **AgentChat** — AutoGen's high-level API for agents and teams. [→](./07-agentic-ai/04-microsoft-autogen.md)
- **Agentic AI** — systems that plan and act toward goals with some autonomy. [→](./04-rag/12-ai-agents-agentic-ai.md)
- **Agentic RAG** — RAG where an agent decides when, what and how to retrieve. [→](./04-rag/01-introduction.md)
- **AgentOps** — the practices and tooling for running agents in production: tracing, evals, security, deployment, monitoring. [→](./08-agentops/01-why-agentops.md)
- **Agents as tools** — wrapping a sub-agent in a tool so another agent can call it. [→](./07-agentic-ai/00-course/d-langchain-agents/02-multi-agent-research-assistant-with-langchain.md)
- **AIMessageChunk** — a partial AI message emitted while streaming. [→](./07-agentic-ai/00-course/f-build-an-agentic-chatbot/03-streaming-chat-threading.md)
- **ANN (approximate nearest neighbor)** — fast search that returns close-to-best matches. [→](./04-rag/06-vector-embedding-vector-databases.md)
- **Answer relevance** — whether the answer addresses the question. [→](./04-rag/21-adaptive-rag-self-rag.md)
- **Answer relevance check** — verifying the answer addresses the question. [→](./05-advanced-rag/03-self-rag.md)
- **Answer relevancy** — how directly the answer addresses the question. [→](./05-advanced-rag/07-rag-evaluation.md)
- **API key** — secret token that authenticates you to a service and bills your account. [→](./00-python-for-ai/10-api-keys-env.md)
- **args_schema** — the Pydantic model that defines a tool's arguments. [→](./07-agentic-ai/00-course/c-python-for-agents/02-pydantic-for-agents.md)
- **Artifact** — an output a task produces. [→](./08-agentops/03-a2a-agent-to-agent-communication.md)
- **ASGI / Uvicorn** — the async server interface and the server that runs FastAPI apps. [→](./03-prompting-llm-apps/08-streamlit-fastapi-front-ends.md)
- **AssistantAgent** — LLM-backed agent that can call tools. [→](./07-agentic-ai/04-microsoft-autogen.md)
- **Attributes** — key/value metadata on a span (model, tokens, user ID). [→](./08-agentops/04-tracing-observability.md)
- **Autonomous RAG** — RAG that plans, executes and evaluates its own multi-step retrieval. [→](./04-rag/18-autonomous-rag.md)
- **Autonomy** — how much of the control flow the model decides instead of your code. [→](./07-agentic-ai/00-course/a-orientation/02-agentic-ai-learning-roadmap.md)

## C

- **Cache invalidation** — removing entries that are stale because the source changed. [→](./04-rag/23-cache-rag-with-langgraph.md)
- **Cached tokens** — input tokens served from the prompt cache at a reduced price. [→](./02-calling-models/07-tracking-tokens-cost.md)
- **Cardinality** — number of unique label combinations; high cardinality kills metric stores. [→](./08-agentops/11-production-monitoring.md)
- **Catastrophic forgetting** — losing general ability after training on a narrow task. [→](./06-fine-tuning/02-when-to-fine-tune.md)
- **Causal LM** — a model that predicts the next token from the previous ones. [→](./06-fine-tuning/05-hugging-face-transformers.md)
- **Causal mask** — blocks attention to future tokens. [→](./01-llm-basics/02-transformers-attention.md)
- **Chain-of-thought** — intermediate reasoning written before the final answer. [→](./03-prompting-llm-apps/02-zero-shot-few-shot-chain-of-thought.md)
- **Chat Completions** — OpenAI's message-list endpoint; the de-facto standard format. [→](./02-calling-models/01-chat-apis.md)
- **Chat template** — the model-specific way messages are turned into a token string. [→](./06-fine-tuning/03-datasets-for-fine-tuning.md)
- **ChatState** — the graph's state schema; here just a list of messages. [→](./07-agentic-ai/00-course/f-build-an-agentic-chatbot/01-chatbot-skeleton-in-langgraph.md)
- **Checkpoint** — a snapshot of state plus metadata at one step. [→](./07-agentic-ai/00-course/f-build-an-agentic-chatbot/02-agent-persistence.md)
- **Checkpointer** — LangGraph component that saves state per thread so conversations can resume. [→](./03-prompting-llm-apps/06-conversation-memory.md)
- **Chunk** — a small piece of a document that is embedded and retrieved as one unit. [→](./04-rag/02-introduction-to-rag.md)
- **Chunk size / overlap** — length of each chunk and how much consecutive chunks share. [→](./04-rag/08-advanced-chunking-preprocessing.md)
- **Chunking** — splitting long text before embedding. [→](./01-llm-basics/04-embeddings.md)
- **CI/CD** — automatically testing (CI) and releasing (CD) every change. [→](./07-agentic-ai/00-course/f-build-an-agentic-chatbot/07-ci-cd-to-aws-with-docker-and-github-actions.md)
- **Citation** — a reference from an answer back to the source chunk or page. [→](./04-rag/30-end-to-end-rag-document-search-project.md)
- **Class** — a blueprint defining attributes and methods. [→](./00-python-for-ai/06-object-oriented-python.md)
- **CLIP** — model that embeds images and text into a shared vector space. [→](./04-rag/11-multi-modal-rag.md)
- **Code executor** — component that runs model-written code, ideally in a sandbox. [→](./07-agentic-ai/04-microsoft-autogen.md)
- **Coercion** — converting compatible input (`"3"` → `3`) during validation. [→](./00-python-for-ai/08-pydantic.md)
- **Cold start** — delay when a sleeping or scaled-to-zero service receives its first request. [→](./03-prompting-llm-apps/09-deploying-an-llm-app.md)
- **Collection / index / namespace** — a named group of vectors inside a database. [→](./04-rag/07-vector-stores-vector-databases.md)
- **ColPali** — retrieval that embeds page images directly and matches query tokens to page patches. [→](./04-rag/11-multi-modal-rag.md)
- **Command** — a node return type that combines a state update with a `goto`. [→](./07-agentic-ai/00-course/e-langgraph-core/02-langgraph-core-components.md)
- **Commit** — a snapshot of staged changes with a message and an ID (SHA). [→](./00-python-for-ai/13-git-github.md)
- **Compile** — turns the `StateGraph` builder into a runnable graph. [→](./07-agentic-ai/00-course/f-build-an-agentic-chatbot/01-chatbot-skeleton-in-langgraph.md)
- **Completion-only loss** — computing training loss only on the assistant's tokens. [→](./06-fine-tuning/03-datasets-for-fine-tuning.md)
- **Comprehension** — expression that builds a list, dict or set from an iterable. [→](./00-python-for-ai/04-control-flow-comprehensions.md)
- **conda** — package and environment manager from Anaconda; handles Python and non-Python dependencies. [→](./04-rag/04-vs-code-anaconda-setup.md)
- **Conditional edge** — an edge whose target is chosen at runtime from state. [→](./04-rag/14-langgraph-basics.md)
- **Conditional expression** — `a if cond else b` in one line. [→](./00-python-for-ai/04-control-flow-comprehensions.md)
- **Container image** — a packaged app with its dependencies, runnable anywhere Docker runs. [→](./03-prompting-llm-apps/09-deploying-an-llm-app.md)
- **Content blocks** — provider-independent representation of message parts (text, reasoning, tool calls, images). [→](./04-rag/13-updated-langchain.md)
- **Content gap** — the answer simply isn't in the corpus. [→](./05-advanced-rag/09-rag-failure-modes-debugging.md)
- **Context** — the retrieved text placed in the prompt. [→](./04-rag/02-introduction-to-rag.md)
- **Context / context window** — the input the model sees at once (prompt + history + its own output so far). [→](./01-llm-basics/01-what-is-an-llm.md)
- **Context engineering** — choosing what goes into the context window at each step. [→](./07-agentic-ai/00-course/i-safety-quality-ops/01-harness-engineering.md)
- **Context isolation** — each sub-agent sees only the input it is given, not the full history. [→](./07-agentic-ai/00-course/d-langchain-agents/02-multi-agent-research-assistant-with-langchain.md)
- **Context manager** — an object used with `with` that sets up and tears down (e.g. closes a file). [→](./00-python-for-ai/07-error-handling-files.md)
- **Context precision** — how relevant and well-ranked the retrieved chunks are. [→](./05-advanced-rag/07-rag-evaluation.md)
- **Context recall** — how much of the needed information was retrieved. [→](./05-advanced-rag/07-rag-evaluation.md)
- **Context window** — max total tokens per request. [→](./01-llm-basics/03-tokens-context-windows-cost.md)
- **Contextual chunk header** — document/section info prepended to a chunk before embedding. [→](./04-rag/08-advanced-chunking-preprocessing.md)
- **Continuous batching** — adding new requests to a running batch instead of waiting, which raises GPU use. [→](./06-fine-tuning/08-serving-a-fine-tuned-model-behind-an-api.md)
- **Coroutine** — the object an `async def` function returns; runs when awaited. [→](./00-python-for-ai/12-async-basics-youll-see-in-agents.md)
- **Corrective RAG (CRAG)** — RAG with a retrieval evaluator that triggers corrective actions on poor results. [→](./04-rag/20-corrective-rag.md)
- **Cosine similarity** — angle-based closeness score. [→](./01-llm-basics/04-embeddings.md)
- **Crew** — a set of agents and tasks run under a process. [→](./07-agentic-ai/03-crewai.md)
- **Cross-encoder** — model that scores a query–document pair jointly; used for reranking. [→](./04-rag/09-hybrid-search-strategies.md)
- **Cypher** — declarative, pattern-based query language for graphs (Neo4j, openCypher). [→](./04-rag/28-graph-databases-cypher.md)
