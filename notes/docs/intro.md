## What these notes are

This is my study log for becoming an **AI engineer**: someone who builds reliable products on top of LLMs, not someone who trains them from scratch. The notes follow [the roadmap](./roadmap.md), from Python basics to production agents:

| Stage | What I'm learning |
| :---: | --- |

| 1 | LLM basics: tokens, embeddings, sampling, limitations |
| 2 | Calling models: chat APIs, streaming, structured outputs, tools, cost |
| 3 | Prompting & LLM apps: prompts, memory, LangChain, deployment |

| 8 | AgentOps: tracing, evals, security, CI/CD, monitoring |

## Why I keep them

- **Writing forces understanding.** If I can't explain it in a TL;DR, I don't know it yet.
- **Interview prep.** Every note ends with quick-fire questions, and the [interview page](./interview-prep.md) collects the big ones.
- **A reference I trust.** When I build something, I come back here instead of searching the web again.

## How each note is laid out

- **TL;DR**: the idea in a few sentences.
- **The concept**: tables, diagrams and small runnable Python snippets.
- **Key terms**: definitions, which are also collected in the [glossary](./glossary.md).
- **Interview quick-fire**: short questions with short answers.

Project notes add an architecture diagram, setup, code, stretch goals, and a "What I learned" section I fill in after building.
